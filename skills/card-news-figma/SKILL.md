# Card News → Figma

주제나 자료를 받아 **표지 1장 + 본문 N장 + 마무리 1장**으로 된 카드뉴스를 기획하고, Figma에 편집 가능한 레이어(텍스트·컴포넌트·색상 변수)로 만든다. 결과물은 디자이너가 바로 다듬을 수 있는 원본이어야 하므로 이미지 한 장으로 굽지 않는다.

## 전체 흐름

1. 입력 파악 → 2. 리서치(필요 시) → 3. 카피 기획 → 4. 스타일 결정 → 5. Figma 생성 → 6. 검수·수정 → 7. 보고

### 1. 입력 파악

어떤 형태의 입력이든 받는다: 주제 한 줄, 붙여넣은 글, 링크, 파일, 앞선 대화에서 만든 결과물(예: 주간 아이디어 정리).

요청에 없으면 아래 기본값을 쓰고, 정말 결과가 달라지는 것만 한 번에 묶어서 묻는다(사용자가 자리에 없으면 묻지 말고 기본값으로 진행한 뒤 보고에 적는다).

| 항목 | 기본값 |
|---|---|
| 본문 카드 수 | 3장 (요약할 덩어리 수에 맞춰 2–6장) |
| 크기 | 1080×1350 (인스타 피드 4:5). 정사각 1080×1080, 스토리 1080×1920도 가능 |
| 언어 | 사용자 언어 |
| 브랜드/채널명 | 사용자 메모리·프로필에 있으면 사용, 없으면 주제명 |
| 포인트 수 | 카드당 3개 (2–4개, 모든 카드 동일하게) |
| 편한 눈 모드 | Default + Sepia·Dark 변수 모드 자동 포함, 처음 보이는 모드는 Default |

"눈 편하게", "세피아", "다크", "밤에 보기 좋게" 같은 말이 있으면 `comfort.preview`를 `sepia`/`dark`로 정한다. 모드가 필요 없다고 하면 `comfort.modes: []`.

### 2. 리서치

- 주제만 주어지고 사실·수치가 필요한 내용(뉴스, 통계, 정책, 제품)이면 먼저 웹 검색으로 근거를 모은다. 공식 발표·원 출처를 우선하고, 날짜를 확인한다.
- 사용자가 자료를 줬다면 그 자료가 우선이다. 추가 검색은 빈 곳을 메울 때만.
- 수치는 반드시 출처와 함께 적고, 출처 문장을 그대로 베끼지 말고 자기 말로 바꾼다.
- 의견·팁형 주제(예: "회의 잘하는 법")는 리서치 없이 기획해도 된다.

### 3. 카피 기획

카드뉴스는 스크롤하다 멈춰 읽는 매체라, 한 장에 한 메시지만 담는다. 아래 구조로 먼저 텍스트 초안을 정리한다.

- **표지**: kicker(시리즈명·카테고리, 영문 대문자 가능) / 제목 2줄 이내 / 부제(날짜·대상·한 줄 요약)
- **본문 카드**: 태그(카테고리 2–8자) / 제목 2줄 이내 / 포인트 N개(라벨 + 설명) / 핵심 관점 1–2줄 / 출처
- **마무리**: 기억할 한 문장(2줄) / 보조 설명 1–2줄 / CTA(저장·팔로우·다음 편)

포인트 라벨은 주제에 맞게 고른다. 숫자가 있으면 숫자(`62%`, `3배`), 개념이면 키워드(`도구`, `흐름`), 절차면 단계(`STEP 1`), 비교면 `Before`/`After`. 라벨은 4자(영문 7자) 안팎이어야 190px 칸에 들어간다.

글자 수 가이드(1080 폭, Pretendard 기준. 넘치면 카드가 잘린다):

| 요소 | 한 줄 최대 | 줄 수 |
|---|---|---|
| 표지 제목 | 한글 약 8자 | 2–3줄 |
| 본문 제목 | 약 13자 | 2줄 |
| 포인트 설명 | 약 22자 | 2줄 |
| 핵심 관점 | 약 26자 | 2줄 |
| 마무리 제목 | 약 9자 | 2줄 |

**줄바꿈은 직접 `\n`으로 넣는다.** Figma는 한글 어절 단위 줄바꿈(keep-all)을 지원하지 않아 자동 줄바꿈 시 "프로토타입\n을"처럼 단어가 쪼개진다. 의미 단위로 끊어 두면 이 문제를 피할 수 있다.

### 4. 스타일 결정

주제의 분위기에 맞춰 팔레트를 고른다. 사용자가 브랜드 색을 주면 그 색을 `accent`로 쓰고 나머지는 아래 규칙으로 맞춘다(`accentSoft`는 accent를 아주 연하게, `onDarkMuted`는 accent 기운이 도는 밝은 회색).

| 프리셋 | 어울리는 주제 | paper | ink | accent | accentSoft | onDarkMuted |
|---|---|---|---|---|---|---|
| Electric | IT·AI·UX·스타트업 | #F4F2EC | #14161A | #2F4BFF | #E4E8FF | #AEB4C8 |
| Forest | 재테크·ESG·건강·식품 | #F3F4EE | #142019 | #1F7A4D | #DDEFE4 | #A9C2B4 |
| Coral | 라이프스타일·마케팅·이벤트 | #FBF5F0 | #1E1513 | #E8553D | #FCE3DC | #CDB3AC |
| Ink | 정책·리포트·교육·공지 | #F5F5F2 | #111318 | #111318 | #E6E7EA | #9EA3AD |
| Violet | 크리에이티브·문화·콘텐츠 | #F6F3F8 | #191424 | #6B3FE0 | #ECE4FF | #B9AFD1 |

`muted`(#6B6F78 계열), `onDark`(#FFFFFF), `line`(paper보다 조금 어두운 색)은 대부분 그대로 둔다. Ink 프리셋처럼 accent가 어두우면 표지가 검정이 되므로 괜찮은지 판단한다.

**편한 눈 모드.** 스크립트가 고른 프리셋에서 Sepia·Dark 값을 자동으로 만들어 같은 변수 컬렉션의 모드로 넣으므로 따로 팔레트를 고를 필요가 없다.

| 모드 | paper | 본문 글자 | 진한 배경(인사이트·마무리) | accent |
|---|---|---|---|---|
| Sepia | #F4ECD8 | #3B3229 | #4A3F35 | 프리셋 accent를 갈색(#8B6F4E) 쪽으로 35% 섞음 |
| Dark | #1C1D21 | #E4E1DA | #2A2C31 | 프리셋 accent를 흰색 쪽으로 20% 섞음, 표지는 accent와 배경을 섞은 차분한 톤 |

accent 계열 글자와 표지 배경은 대비 4.5:1이 될 때까지 자동 보정되므로 Ink처럼 어두운 프리셋도 Dark에서 읽힌다. 특정 색을 직접 정하려면 토큰 이름으로 덮어쓴다: `comfort.dark: { 'bg/paper': '#18191C' }`.

폰트는 한글이면 Pretendard → Noto Sans KR → IBM Plex Sans KR 순서, 영문 전용이면 Inter를 우선한다(스크립트가 자동으로 있는 것을 고른다).

### 5. Figma 생성

1. 먼저 Figma 관련 스킬을 로드한다: `figma-create-new-file`, `figma-use`, `figma-generate-design` (이름이 다르면 비슷한 Figma 스킬). `use_figma` 호출 시 `skillNames`에 로드한 스킬 이름을 넣는다.
2. 사용자가 Figma 파일 URL을 줬으면 그 파일에 만든다(빈 공간 오른쪽에 자동 배치). 없으면 `whoami`로 플랜을 확인하고 새 디자인 파일을 만든다. 플랜이 여러 개면 Full seat인 개인/메인 팀을 고르고, 판단이 어려우면 묻는다. 파일 이름: `카드뉴스 · <주제> (<날짜>)`. Starter 플랜은 컬렉션당 변수 모드가 1개로 제한될 수 있다. 이때 스크립트는 `comfort.preview` 모드 하나만 만들고 `modesUnavailable: true`를 반환하므로, 보고에 "모드 전환은 유료 플랜에서 가능"이라고 적는다.
3. `create_session`으로 세션을 만들고 모든 Figma 호출에 sessionId를 넣는다.
4. `scripts/build_card_news.js`를 읽고 **CONFIG 블록만** 3–4단계 내용으로 채워 `use_figma` 한 번에 실행한다. 스크립트가 하는 일:
   - 팔레트를 Default/Sepia/Dark 모드가 있는 `CardNews/<이름>` 색상 변수 컬렉션으로 만들고 모든 색을 변수에 연결
   - 본문 카드를 `Card/Content` 컴포넌트 하나로 만들고 텍스트 속성(번호·태그·제목·라벨·포인트·인사이트·출처)으로 인스턴스마다 내용 교체 → 사용자가 디자인 한 번 고치면 모든 카드에 반영
   - 표지·마무리는 일반 프레임으로, 전체를 가로 오토레이아웃 래퍼에 배치
   - 넘침(overflow)·대비(contrastWarnings) 검사 결과와 노드 ID 반환
5. 스크립트를 크게 바꿔야 하는 요청(예: 이미지 카드, 다른 레이아웃)이면 스크립트를 출발점으로 수정하되, 텍스트는 편집 가능하게, 반복 요소는 컴포넌트로 유지한다.

### 6. 검수·수정

- 반환값의 `overflow`에 카드가 있으면 해당 카드 텍스트를 줄여 다시 설정한다.
- 래퍼 전체 스크린샷을 한 번 찍어(`get_screenshot`, maxDimension 3000) 확인할 것: 텍스트 잘림, 어절이 쪼개진 줄바꿈, 비어 있는 라벨, 표지 제목이 너무 긴지, 색 대비.
- 반환값의 `contrastWarnings`에 항목이 있으면 해당 토큰을 `comfort.<mode>`로 덮어써 다시 실행한다.
- 편한 눈 모드는 래퍼에 `setExplicitVariableModeForCollection(collection, modeId)`로 Sepia·Dark를 차례로 적용해 스크린샷을 한 번씩 확인하고, 끝나면 `comfort.preview` 모드로 되돌린다.
- 고칠 게 있으면 인스턴스는 `setProperties`로 해당 속성만 바꾼다(속성 키는 `inst.componentProperties`에서 `'Point 1#…'`처럼 이름으로 찾는다). 수정 후 스크린샷은 한 번만 더.

### 7. 보고

짧게 알린다: Figma 파일 링크, 카드 구성(장별 제목 한 줄씩), 쓴 팔레트·크기, 편집 방법(컴포넌트 속성·색상 변수), 편한 눈 모드 전환 방법(래퍼 선택 → 오른쪽 패널 Layer의 변수 모드에서 Default/Sepia/Dark 선택), 기본값으로 정한 것. 리서치를 했다면 출처 링크를 덧붙인다.

## 예시

**입력:** "직장인 재테크 기초를 카드뉴스로 만들어줘"
→ Forest 팔레트, 본문 3장(비상금 → 연금저축/IRP → ETF 적립), 라벨은 `STEP 1` 형식, 세율 등 수치는 공식 출처 검색 후 기입, 마무리 CTA "저장해두고 월급날 다시 보기 →".

**입력:** (앞선 대화의 주간 UX 아이디어 3개) "이걸 카드뉴스로"
→ 리서치 생략, 대화 내용 요약. Electric 팔레트, 아이디어 1개 = 카드 1장, 수치가 있는 카드는 숫자 라벨, 나머지는 키워드 라벨.
